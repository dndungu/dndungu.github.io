MCP endpoint

ndungu.dev exposes a lightweight MCP server for public, non-sensitive references with streamable HTTP transport.

Endpoint and protocol

URL: https://ndungu.dev/mcp

Transport: Streamable HTTP

Protocol: 2025-03-26

Use JSON-RPC methods (initialize, tools/list, tools/call) via POST.

View server card

Tool list

  • get_site_navigation — returns homepage, about, contact, privacy, audit, and API links.
  • get_developer_resources — returns OpenAPI, MCP card, and machine-readable index links.
  • get_contact_brief — returns practical contact fields for scheduling.

Fallback paths

If an endpoint is wrong or missing, request headers Accept: text/markdown to get a markdown recovery page at the 404 response.
