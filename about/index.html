About David Ndungu

I'm a software engineer with 20+ years building software, including eight years at Zendesk across test, senior, and staff engineering roles. I have also run a development consultancy and founded Zatiti, an e-commerce SaaS that reached 50 paying retailers. Today I build open-source agent infrastructure and help engineering teams use coding agents effectively. I also build Sire.

What I actually build

My work spans verification with Kazi, decision history with Dira, agent memory with Serenity (in active development), and ML infrastructure with Zerfoo. Building and using these tools gives me concrete problems to work through, from agent handoffs to model execution.

What I do for clients

I help developers and engineering teams improve the workflow around Claude Code and other coding agents: acceptance checks, context, integrations, and handoffs. We start with one concrete bottleneck, agree on the scope and fee, and implement a result your team can evaluate and maintain. See the engagement and the engineering behind it.
